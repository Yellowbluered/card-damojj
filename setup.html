⚠️ 你而家用緊 App 內置瀏覽器，Google 授權一定會失敗

你頭先見到嘅「頁面載入失敗：請重新嘗試或在系統瀏覽器中打開」就係因為咁樣 —— Google 唔准喺微信／QQ／IG 嘅內置瀏覽器做登入授權。

解決方法（任揀一個）：

  • 電腦：撳呢個視窗右上角 ⋯ 或 ↗ → 在瀏覽器中開啟
  • 手機：撳右上角 ··· → 在瀏覽器開啟（會用 Safari / Chrome）
  • 或者複製下面條連結，貼去 Chrome / Edge / Safari 開

重要：成個設定過程（試算表 → Apps Script → 授權 → 部署）都要喺同一個正常瀏覽器做完。

🔧 卡住咗？對號入座


    

      撳「部署」之後，授權畫面白畫面／「頁面載入失敗」
      

        
原因：用咗微信／QQ／IG 等 App 嘅內置瀏覽器，Google 會拒絕授權。

        
做法：用電腦嘅 Chrome／Edge 打開 script.google.com，
        搵返你頭先個專案（「未命名的專案」），之後只需要重新做第 4 步：部署。
        試算表同已貼上嘅代碼都仲喺度，唔需要重頭做。

      

    


    

      授權頁彈「Google 未驗證這個應用程式」
      

        撳左下角「進階」→「繼續前往（不安全）」→「允許」。呢個 script 係你自己嘅，唔會有安全問題。
      

    


    

      「測試連線」失敗，或者回應唔係 JSON
      

        
1. 部署時「具有應用程式存取權的使用者」一定要揀「任何人」（唔係「只有我自己」）。

        
2. 網址結尾一定要係 /exec，唔係 /dev。

        
3. 改過代碼之後要重新部署（部署 → 管理部署作業 → 編輯 → 版本揀「新版本」），否則行嘅仲係舊代碼。

      

    


    

      手機開到網站但同步唔到
      

        同一個原因：確認你手機係用正常瀏覽器開分享連結，而唔係喺微信對話框入面直接開。
        喺微信可以先「複製連結」，再貼去 Safari／Chrome。
      

    


    

      公司／學校 Google 帳戶用唔到 Apps Script
      

        機構帳戶經常封鎖 Apps Script 同 Drive 分享。改用個人 Gmail 帳戶開試算表就得。
